# 项目决策记录

## 2026-11-03

- 前台采用原生 HTML、CSS、JavaScript，不引入框架或构建步骤，适配 COS 静态托管。
- 数据规模按数百条设计：浏览器一次性加载两张 JSON，筛选在本地同步完成，不引入分页服务。
- 系列与谷子均使用 Decap file collection 的 list 字段维护，保持现有 JSON 数组结构。
- 视觉严格采用茉莉白、嫩黄、香槟金与深棕灰；方格纸、虚线和蕾丝扇形作为手帐材质语言。
- 当前示例图片为本地原创 SVG 制品示意，不冒充官方商品图；正式收录时替换为 Cloudinary 图片。
- 所有图片统一经过 `imgUrl` 与 `renderImage`，失败时使用一次性兜底标记，避免错误事件死循环。
- 筛选条件可叠加，材质多选采用 OR；平台在当前单选下拉中转换为一项数组，保留未来多选扩展能力。
- 详情浮层不提供购买、分享或收藏按钮，只保留关闭操作；支持 Esc、背景点击、焦点归还与背景滚动锁定。
- 前台不保存任何读者个人数据。站长授权密钥仅存于 SCF 环境变量，不进入静态站点。
- 部署仅组装公开目录后同步 COS，避免把云函数、工作流和项目文档上传到公开存储桶。
