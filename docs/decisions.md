# 项目决策记录

## 2026-11-03

- 前台采用原生 HTML、CSS、JavaScript，不引入框架或构建步骤，适配 COS 静态托管。
- 数据规模按数百条设计：浏览器一次性加载两张 JSON，筛选在本地同步完成，不引入分页服务。
- 系列与谷子均使用 Decap file collection 的 list 字段维护，保持现有 JSON 数组结构。
- 视觉严格采用茉莉白、嫩黄、香槟金与深棕灰；方格纸、虚线和蕾丝扇形作为手帐材质语言。
- 当前示例图片为本地原创 SVG 制品示意，不冒充官方商品图；正式收录时替换为 Cloudinary 图片。
- 所有图片统一经过 `imgUrl` 与 `renderImage`，失败时使用一次性兜底标记，避免错误事件死循环。
- 筛选条件可叠加，材质多选采用 OR；平台在当前单选下拉中转换为一项数组，保留未来多选扩展能力。
- 详情浮层不提供购买、分享或收藏按钮，只保留关闭操作；支持 Esc、背景点击、焦点归还与背景滚动锁定。
- 前台不保存任何读者个人数据。站长授权密钥仅存于 SCF 环境变量，不进入静态站点。
- 部署仅组装公开目录后同步 COS，避免把云函数、工作流和项目文档上传到公开存储桶。

## 2026-11-27

- 保持单 `index.html` 与 Hash 路由，新增标题页、Special 档案页和设置页，不引入框架或构建步骤。
- 首次访问标题页播放一次可跳过的开机演出，结束后由访客自主导航；回访首页直落图鉴，明确的路由链接优先。
- 标题页使用双端独立静态素材，不引入视频或粒子；减少动态效果偏好下禁用演出与白闪转场。
- Nickname 统一在 Special 页维护；备份新增可选 Nickname 字段并兼容旧备份，已有 Nickname 不被导入覆盖。
- 清空个人数据包括仓库、心愿单、金额、数量和 Nickname，保留标题页首访标记，不调用 `localStorage.clear()`。
- 仓库收集度按已入库／总收录，心愿页进度按心愿数／总收录；Special 收集度按已入库／总收录。
- 设置页采用 Decap 结构化板块字段，普通条目自动编号，QA 独立维护；数据更新日期由部署工作流生成。

## 2026-11-28

- 移除随站背景音乐，背景音乐和六槽位菜单语音均由访客本地导入，网站不提供音频素材；全站声音总开关默认开启，刷新后保留媒体但不自动播放背景音乐。
- 菜单语音只在指定菜单链接跳转到不同页面时播放；当前槽位优先，空槽位从全部已导入语音随机选择，播放不阻塞导航。
- 自定义收藏卡照片在档案页本地裁剪，图鉴页与档案页同步显示，仅档案页提供编辑入口；恢复默认图片需要确认。
- 照片和音频使用 IndexedDB，轻量偏好继续使用 localStorage。新备份采用 ZIP 数据清单与媒体文件，照片默认包含、音频可选包含，旧版 JSON 保持兼容，媒体覆盖前需要确认。
- 清空个人记录时由访客勾选是否同时删除全部本地媒体，默认不删除；显示模式和声音设置保留。访客文案统一使用 Nickname。
- 首页每次打开或刷新都播放柔和的方向性清晰化演出，点击空白或 Esc 可跳过，站内返回标题页不重播，不再保存首访标记。
- 清单截图仅导出访客实际填写的 Slogan，空白时不使用默认日文也不保留占位；设置页开放返回顶部和前往底部按钮。
- 无痕模式不增加媒体降级存储，设置页 QA 明确 IndexedDB 受限时照片和音频可能导入失败，并列出支持的媒体格式、大小和备份格式。
- COS 部署仅发布前台必要文件，通过远端 ETag 与本地 MD5 跳过未变化文件，单请求 60 秒超时且临时网络错误最多尝试 4 次；成功后清理旧 `assets/audio/`，不批量删除其他远端文件。
